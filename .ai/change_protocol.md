# 🛑 AI Change Protocol & Governance

## Architectural Changes
Any modification involving database schemas, framework selection, directory structures, authentication mechanics, core system dependencies, or public API contracts must follow this strict compliance track:
1. Boss profile analyzes ecosystem impact down the stream.
2. The strategic change rationale is logged in .ai/decisions.md.
3. The targeted scope parameters are explicitly updated inside .ai/active_task.md.
4. Code Mode may begin execution ONLY after the developer gives the green light on the updated task blueprint.

## Forbidden Actions
Code Mode and Debug Mode are strictly prohibited from silently or independently conducting architectural migrations or structural directory re-organizations.
