- 2026-10-10: **Wave 1 complete — va-harness execution engine (ADR-015).** New crate `va-harness` with five modules: `session` (append-only transactional trajectory DAG with per-node state hashing, fork, rollback, replay, JSONL persistence), `patcher` (deterministic hash-anchored editing with 1-hop structural recovery and hard rejection of ambiguous targets), `review` (git checkpointing and per-step delta isolation), `judge` (deterministic anti-slop gate: slop comments, placeholders, unsafe primitives, import churn, excessive churn, one targeted retry), `engine` (Observe → Think → Patch → Verify → Judge loop, model-agnostic via a `Planner` trait). `va-core` gains `knowledge` (curated benchmarks + name heuristics: version parsing, reasoning/speed tag boosts, zero-config auto-combo across six roles) and `router_client` (Vibe Router with optional Bearer/X-API-Key auth, chunked decoding, tolerant payload parsing, offline fallback). CLI gains `vibe-assembly run --auto-combo`, `vibe-assembly patch <file> --target <hash>`, and `vibe-assembly blocks <file>`. Desktop gains a live Execution Harness panel. 128 tests pass, clippy clean. Research note: the deepseek-harness reference is TypeScript with a flat event log (no DAG/state-hash/rollback), and oh-my-pi anchors hashes to files not blocks with tree-sitter blocks by line — so behaviors were reimplemented rather than ported, using FNV-1a and indentation-scoped blocks to stay dependency-free offline.
