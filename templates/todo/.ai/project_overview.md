# 📝 Project Overview
Core Vision: A fast, local to-do list. This workspace began from the standard `todo` template — a working baseline already exists in `app/`.
Target Core Features:
- [x] Add / complete / delete tasks (localStorage persistence) — shipped in template
- [x] All/Open/Done filters — shipped in template
- [ ] Due dates and overdue highlighting
- [ ] Reordering (drag or up/down)
Strategic Non-Goals: No accounts, no backend — local-first until the user explicitly says otherwise.
