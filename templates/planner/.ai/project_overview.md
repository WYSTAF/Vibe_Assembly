# 📝 Project Overview
Core Vision: A personal planner that helps the user capture goals and organize their week. This workspace began from the standard `planner` template — a working baseline already exists in `app/`.
Target Core Features:
- [x] Goal list with add/complete (localStorage persistence) — shipped in template
- [ ] Weekly view with clickable days
- [ ] Task scheduling per day
- [ ] Progress overview / stats
Strategic Non-Goals: No accounts, no backend, no sync — local-first until the user explicitly says otherwise.
